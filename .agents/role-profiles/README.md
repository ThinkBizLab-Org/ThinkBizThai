# Role profiles

`roles.json` assigns stable, vendor-neutral names to the delivery roles agreed for ThinkBizThai. A role profile is not an agent capability declaration and is never an `agent_run_id`.

Before any package becomes `ready`, the dispatcher must match its required skill profiles to real capability declarations and populate distinct `agent_run_id` values in the package manifest. The canonical skill and independence rules remain in the Sprint 0A Decision Register and `CONTRIBUTING_AGENTS.md`.
