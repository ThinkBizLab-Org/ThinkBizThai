## 8. Findings

- **Q0-255R2-1 (minor for Q0, not blocking `test_verified`; the security grade is A1's).** The walk still misses
  imports that RFC-2026-007 Amendment 2026-10-11 and the handoff say cannot hide:
  - **A TypeScript module a guard imports (R14, R15), with no misread.** `CODE_MODULE` is `/\.[cm]?js$/`, so a reached
    `.mts`, `.ts` or `.cts` is put in the closure but never read: what it imports is invisible, and the edit prints
    `risk`. Node 24.20.0 runs such a module. The amendment's lane rules say "A module it cannot read … makes the pull request
    governance"; this one is not read and is not a problem.
  - **Behind a misread, three specifiers written as plain strings (R12, R13, R16)**: a path through a directory link
    (`./lnk/evil.mjs`), an extensionless `require`, a directory `require`. The raw backstop drops a candidate that
    names no file, so it neither follows nor flags them; outside a misread the same specifiers are problems (R11, R13b).
    §D (corrected 2026-10-11) says what stays hidden behind a misread is a specifier "computed from an expression" or "a
    mechanism the scanner does not model", and the handoff's second known limitation says the same; these are neither.
  - At this head there is no `.ts`/`.mts`/`.cts` file and no link [measured: `git ls-tree -r 39de17ae`], so no pull
    request prints a lower lane today; each shape needs a guard or its import chain planted first, which is itself a
    governance edit read by all four roles. That is the same character as A1-255r2-1, which A1 graded Low. Either the
    walk fails closed on them (for example, a reached module that is neither `.js`/`.mjs`/`.cjs` nor data is a problem;
    a backstop candidate that names no file but whose path passes through a link, or resolves by CommonJS extension or
    index rules, is followed or a problem), or §D and the handoff name them. Under RFC-2026-025 §5 item 6 and R0's C1
    (no security finding of any grade open), whether this blocks the press depends on A1's grading, not mine.

  line-break removal from a specifier (B4), CR, U+2028 and U+2029 ending a `//` comment in the wide form (B10), and the
  link check on the additive walk for a non-code link (B20). Three small cases would kill them: R8's and R9's probes as
  test rows, and a `.json` link imported by `scripts/db/run.mjs`.
