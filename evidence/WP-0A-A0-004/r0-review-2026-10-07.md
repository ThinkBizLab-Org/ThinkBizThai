## 3. Findings (all advisory; none blocks, none is stop-the-line, none is a security finding of the §5 item 6 kind)

- **R0-1 (Low, correctness of the label).** A crash of the base classifier before its own `try` (an import
  failure, a syntax error) exits 1, and the step reports it as the classifier's classification
  ("exited 1 … its reasons follow"). The classifier is run from a scratch copy, so a future `main` that gives
  it a relative import would make every PR print `NOT RECORDS-ONLY` with a stack trace, silently. Fail-closed
  holds in every case; only the information degrades. A test that the copy runs stand-alone, or a check that
  the exit-1 output begins `NOT records-only`, would pin it.
- **R0-2 (Low, reader hygiene).** The classifier prints raw paths, so a crafted file name can put an
  indented `records-only classifier: RECORDS-ONLY` line into the log (E1). The verdict is the column-0
  line and the summary heading; a reader grepping the log unanchored could be misled. It can make nothing
  pass, and the §6.2 reader runs the classifier itself.
- **R0-3 (Low).** The reason sentence (`$2`) goes into the job summary unescaped, and on one path it carries
  `BASE_REF`, a branch name that may contain `<`, `>` and `&` (E2). Reaching it needs a branch in this
  repository, that is write access; the effect is rendered Markdown in a summary only.
- **R0-4 (Low, test coverage).** Mutation M4 survives: nothing pins the `records-only: ` first-line clause.
  Today's classifier never exits 0 without that line, so the clause is defence in depth, unpinned.
- **R0-5 (record consistency, carried, not this increment's).** On `main`, RFC-2026-007's Amendment
  2026-10-06 status line still reads "Proposed 2026-10-06, for the Product Owner's disposition", and the
  manifest's `required_human_authorities[2]` still says that disposition is OWED, although PR #197 merged.
  The new Amendment 2026-10-08 carries no Approved/Proposed token ("implements a step the Product Owner
  already approved"). Whoever records the next state should reconcile the two amendment status lines.
