(`ci.yml:205`). Its body opens with these four lines (`ci.yml:209-212`):

```
if [ "${BASE_REF:-}" != main ]; then
  echo "negative control: the base branch '${BASE_REF:-}' is not exactly main; the control RUNS"

```

The guard comes before any line that can write `skip=true`. It exits 0, so it runs the control and does not fail the job.

code.
