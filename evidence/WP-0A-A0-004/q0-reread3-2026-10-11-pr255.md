## 8. Findings

- **Q0-255R3-1 (minor for Q0, not blocking `test_verified`; the security grade is A1's, the text C0's).**
  RFC-2026-007 Amendment 2026-10-11 §B and §D now say a module "can still hide from it **only if** a guard loads it by
  a path computed at run time (not written as a literal), or by a loading mechanism that names no repository-relative
  path literally"; the classifier's comment says the same, and the handoff's second known limitation says "One class
  can still hide a module". Four shapes in §4, each a guard naming a repository-relative path in **one literal**, each
  behind A1's misread line, print risk and run under node 24.20.0:
  - **R21, the length cap.** `stringNames` drops a span over `STRING_MAX` (4,096 characters); a path padded with `./`
    (or `x/../`) is still one literal and node normalizes it. Unpinned (C11 survives).
  - **R22 and R25, CommonJS runs any extension.** The string rule's "a string that names data … adds nothing: what a
    data file holds runs nothing" does not hold for `require`, which runs `.txt`, extensionless and every other file but
    `.json` and `.node` as JavaScript. (Read from code or by the backstop the same path is reached; only a string is
    treated as data.)
  - **R23, an escaped quote of the literal's own kind.** The span rule splits `'…q0\'z.mjs'` at the escaped quote, raw
    and decoded; the backstop's `specAt` stops there too. This one is a plain `import()`, no alias.

  At this head no guard holds a misread, a `createRequire` alias, a file name with a quote or such a literal; each
  shape needs a guard planted first, a governance edit all four roles read: the same character as A1-255r2-1, A1-255r3-1
  and Q0-255R2-1. Either the walk covers them (for example: no cap, or a cap that fails closed; a string resolving to a
  file that is not `.json` or a known data type is reached, accepting more over-reach; an escape-aware span), or §B,
  §D, the comment and the handoff name them, or drop the "only if" for a statement that does not claim completeness.
  Under R0's press condition (no security finding of any grade open), whether this blocks the press depends on A1's
  grading, not mine.
- **N-1 (note).** R24: a path written as a literal in a JSON file a guard imports, then loaded by an alias. I read this
  as "a path computed at run time" from the guard's code, so inside the residual; the words "not written as a literal"
  could be read the other way. C0's to rule whether the sentence wants "in the guard's code".
- **N-2 (note, R0's to rule).** The string rule reaches every code path named in a test's fixture strings, because
