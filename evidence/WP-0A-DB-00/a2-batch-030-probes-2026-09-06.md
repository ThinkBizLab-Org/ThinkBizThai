# Batch 030 — twelve probes against the static suite

Author: `/claude/a2_industry`. Date: 2026-09-06. Toolchain: node `v24.20.0`, npm `11.19.0`.

A green suite that has never been observed failing is not evidence. Every static assertion batch 030
adds was therefore run against a tree where the thing it asserts had been reversed, and each was
required to go red. This file records what was reversed and what noticed.

## Method

Each probe copies the four files it may touch, applies exactly one reversal, runs

```
LC_ALL=C TZ=UTC node --test tests/db/identity/identity-isolation.test.mjs
```

and requires a non-zero exit; then restores from the copies. The restore is a file copy and **not**
`git checkout`, and that is a correction rather than a preference: two of the four files are
untracked on this branch, and `git checkout -- <tracked> <untracked>` reports an error for the
pathspec it cannot resolve and restores nothing. A first run of these probes did exactly that, so
the mutations accumulated and the later results were not attributable to their own reversal. The
run below is the corrected one; the tree was repaired and the suite re-run green before it started.

## What these probes do NOT establish

They exercise the STATIC half only, which is what this host can run: it has no `psql`, `pg_ctl` or
`docker`, so every live target refuses by design. Nothing here shows that a policy behaves as
written against a database. That is the CI round's job — `make db-migrate-clean`,
`make db-schema-lint` and `make db-rls-smoke` against the `postgres:17` service container, plus the
seven-entry negative control, which is itself the live counterpart of probes 4 and 7.

Two of the twelve are about the CI control rather than about SQL (4 and 7), and they are the ones
worth re-reading: the negative-control entries for `app.industry_packs` and
`app.industry_pack_versions` each rest on ONE case, because those tables have no tenant boundary to
disable and every client case against them is a privilege refusal that survives RLS being switched
off. Probe 7 is the check that the one case they rest on cannot quietly disappear.
