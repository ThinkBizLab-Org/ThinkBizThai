## 3. What remains

- **(15), the command-role closure.** The settled-row closure for an RFC-2026-023 command role waits
  on that RFC's disposition (A1 V1 remedy 3; A1 N2, item 9). A policy for a role that does not
  exist would be a grant reviewed against no caller.
- **(15)/(16) boundary.** A superuser still bypasses the trigger with `session_replication_role =
  replica` or `DISABLE TRIGGER`. That is inherent to a superuser and to the table owner. A later file
  doing either is caught by the trigger probe. `ALTER SYSTEM SET session_replication_role` is not
  transactional, so no drift can exercise it, and it is not covered.
- **(11), by construction.** The probes run as the migration owner. A superuser drift can still forge
  in ways no verdict can see, for example by replacing a `pg_catalog` function. The markers close the
  routes the reviews measured; they do not make a hostile superuser drift safe.
- **(12), a known over-refusal.** `psqlLex` splits a SQL-standard `begin atomic … end` body at its
  inner `;`, so its `end` reads as a statement head. It fails closed, and no drift uses one.
- **(13), scope.** The pinned trigger probe covers `app.approval_requests` only.
- **091-i, scope.** The allowlist covers the two calendar tables only; the general version (every
  RLS table in `app`, A1 R1's "better" remedy) is not attempted here. A grant to a NEW role that no
  existing role inherits would be read too, because the role set is read from `pg_roles`, not named.
  `has_*_privilege` reads effective privilege with the roles' NOINHERIT attribute, so a privilege a
  role could reach only by `SET ROLE` is not counted; no client path issues `SET ROLE`.
- **091-i, the optional case.** C0 H1 also suggested `owner-a-cannot-place-an-item-already-deleted`.
  It is not added: the probe is the forward assertion, and a grant-layer case would sit outside the
  count of seven that 091's per-family negative-control entries hold.
- **Not this batch:** (16), the anonymisation route before batch 160, which must now also account
  for `status`; A5's (h), case variants of zone names and `Etc/UTC`.

## 4. Choices for the Owner or a reviewer

The Owner's four (O1–O4) are in the disposition, with A0's recommendation for each, all UNANSWERED.
In short:

- **O1.** Migration number 126 in MOD-120's range (§1).
- **O2.** Keep `CHECK (decided_at >= created_at)`. Harmless today: no environment holds approval rows
  before G0. Without the INSERT branch it would refuse the 090 fixture, whose literal 2026-09-11
  times predate the load. Adding a CHECK over existing rows fails its migration with no recovery path
  (Q0 F8, A1 F7 on 123); that remediation is still owed before approvals exist anywhere.
- **O3.** The INSERT branch overwrites any `decided_at` a non-client writer inserts, the fixture's
  fixed times included. No case reads them. A1's remedy named the trade-off.
- **O4.** `cancelled` and `expired` are final for every writer that fires triggers (A1's remedy 1).
  No documented flow leaves a terminal state.

For reviewers:

- **R1 (C0 / Q0).** The 090 fixture now carries a behavioural DO block that runs as the loader.
  Fixtures 081, 120 and 121 carry DO blocks that check fixture state, not behaviour. It is the only
  place a test run has a non-client writer.
- **R2 (C0).** 125's replacement is additive. It first asserts 126's trigger and body strictly, then
  keeps 125's two assertions word for word, each widened with `and not exists (<126's shape>)` so the
  final state passes. The strict pair before it, 126's own block and the pinned trigger probe are
  what refuse 125's shape.
- **R3 (C0 / Q0).** The post-migrate test's `fails_with` matcher now also reads a raise with no
  argument and unescapes `''`. 125's block is the first superseded block whose raises have none.
- **R4.** Every pre-existing probe digest moved once, because each drift's `names` joined the
  digested text. The test's comment says which probes changed for other reasons; the pinned trigger,
  grant and default probes are new.
- **R5 (A1).** `feedTranscript` returns redacted stderr to the verdict, which only counts `ERROR:` in
  it and prints nothing new from it.
- **R6 (C0 / A1).** The grant probe's pinned set is literal in `run.mjs` and held to 091's grant
  text by the static test. A batch that changes 091's grants changes both, in one diff.
