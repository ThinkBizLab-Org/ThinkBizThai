## 2. The questions asked

**Secrets, credentials, personal data, private URLs, customer content.** None added. The only URL is the repository's
own PR link, which the repository already cites throughout. The appended text names agent run IDs, commit SHAs, a CI
run ID and the Owner's relayed Thai words, all of which are already on `main`.

**Dropped amendments.** This change narrows only. `amends_without_owning.paths` is the list of files the package may
touch outside its ownership without the branch-scope guard failing. Emptying it removes six permissions and grants
none. A later increment that touches any of the six must declare it again, as the rationale says. That is the guard
working as designed. Five of the six are integrity or test-kit files (`test-kits/integrity-manifest.json`,
`scripts/test-suite-contract.mjs` and others). Dropping them makes it harder for this package to touch a ratchet
silently, which is the safer direction.

**Map re-pin.** This change does not weaken the audit-coverage lint. Only `line` values move, all by the seven lines
that collapsing the `paths` array removes above `open_blockers`. `index` and `quote` are unchanged, and those carry
the substance: each action is held by a named live blocker that still says the quoted words. `line` is a positional
pin that the test checks against the actual file. A wrong pin fails the test. It cannot make the test pass falsely,
because the same assertion requires the blocker's own text on that line. Neither the test nor
`scripts/db/audit-producer-rule.mjs` changed.

**Presser record and A1-G1.** This is consistent with A1-G1. A1-G1 asked that, if A0 presses, the repository basis be
recorded as the PR #213 exception in disposition §2, and that the standing words `ให้ A0 กดทุกตัวในแผน` be quoted only
as relayed context that no disposition records and that does not amend RFC-2026-025 §5 item 6. That record is
already on `main`, inside `open_blockers[204]`: "PRESSER AUTHORITY, A0's record answering A1-G1 and C0 N9". It says
those words, including "are not taken here to amend RFC-2026-025 §5 item 6". This PR does not edit that text, and the
append comes after it.

The append transcribes R0's words whole. R0's sentence names both the §2 exception and the standing words "as
relayed". On its own, that sentence could be read as two co-equal bases. A0 then adds that "the repository basis of
the press stays as recorded above (A1-G1, C0 N9): the PR #213 exception in disposition §2; the standing words are as
relayed". That ties R0's sentence back to the A1-G1 record. It does not restate the standing words as an authority,
and it does not extend them to any PR other than #213. A scribe must not paraphrase R0's verbatim words, so quoting
them whole and qualifying them afterwards is the right form. No merge authority is widened.
