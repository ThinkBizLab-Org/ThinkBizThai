**O1 (observation, not a finding against this PR).** `npm run check` is 717/717 green at `952b91bd`, and so is
A0's `commit-when-clean` run, even though the handoff cites `77dad630` and two substantive paths changed after it.
This is by design: `refresh-author-handoff.mjs` compares the handoff with the branch as it stood **before** the
current commit (`HEAD^`). A handoff cannot cite the commit that contains it.

The cost is that the last commit on a branch is always invisible to the local guard. The pull-request merge in CI
compares against the branch head, so it would catch this. A green local check at a head after a refresh is therefore
not evidence of a fresh handoff. Only the refresh, last and alone, together with CI, is. A0 did not claim otherwise.
