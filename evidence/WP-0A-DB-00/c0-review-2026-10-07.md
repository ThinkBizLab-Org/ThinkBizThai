### F1: "no data path" is not mechanical (Major)

RFC §3 defines L as "no data path" and §4.2 item 7 lists the signals that decide it: `fetch(`, `'use server'`,
`@supabase/`, `/api/`, browser storage, and so on, all searched in the file's **added lines**. In the App Router layout
RFC-2026-029 proposes, a client component reaches the server by importing a server action or a data hook and calling
it; the `'use server'` marker sits in the other file, which may already be on `main`. I classified synthetic diffs with
the PR's own `classifyTier` (probe outside the repository):

| Probe | Added lines in `src/modules/account/ui/DangerZone.tsx` | Tier |
|---|---|---|
| P1 | `import { deleteAccount } from '../actions/delete-account';` + `<button onClick={() => deleteAccount()}>` | **L** |
| P2 | `import { useMutation } from '@tanstack/react-query';` + `useMutation({ mutationFn: saveProfile })` | **L** |

P1 is an irreversible deletion (a stop-the-line class) reached from an L PR with one reader. §4.3 prints a reminder
that the Reviewer confirms the **flag**; nothing asks anyone to confirm the data path, and §4.2 item 7 reads as if the
script had.

**Needed**, either:

- the classifier treats an L file that imports anything outside L paths (other than an allow-list such as `react` and
  the module's own `ui/`/`components/`) as having a data path, so it becomes M with its test rule, or H outside a
  module; or
- §4.2 item 7 and §4.3 say the data-path test is a Reviewer confirmation like the flag, the CLI's L reminder names
  both, and the Reviewer's file records both. The first is the fail-closed choice §2 promises.

### F2: auth words missing from the H path list (Minor)

`H_PATH_WORDS` has `auth`, `login`, `session`, `password`, `oauth`, `token`, but not `signin`, `signout`, `signup`,
`logout`, `logon`, `mfa`, `otp`, `totp`, `passkey`, `webauthn`, `sso`, `saml`, `jwt`, `csrf`, `cookie`. Probes:
`src/modules/account/ui/SignInForm.tsx` with `<form action={signIn}>` → **L**; `apps/web/components/LogoutButton.tsx`
→ **L**; `apps/web/components/MfaPrompt.tsx` → **L**. The camel-case split also misses an all-caps prefix:
`APIClientBadge.tsx` becomes `apiclient`, not `api`. Q-030-4 asks the Owner to approve the list as "wide"; it should
be wide for auth first. **Needed:** add these words, split `[A-Z]+(?=[A-Z][a-z])`, and test one of each.

### F3: injection sinks incomplete (Minor)

H_LINE_SIGNALS' code-injection entry covers `dangerouslySetInnerHTML`, `eval(`, `new Function(` and `<script`.
Probes left at **L**: `apps/web/public/logo.svg` with an `onload="..."` attribute (served same-origin, an SVG handler
runs when the SVG is opened directly); `ref.current.innerHTML = props.html;`; ``<a href={`javascript:${x}`}>``.
**Needed:** add `\bon[a-z]+\s*=` for `.svg`, `\b(?:inner|outer)HTML\s*=`, `insertAdjacentHTML`, `document.write` and
`javascript:`, with tests. A1 should weigh in on the list.

### F4: package and config files inside a module are M (Minor)

`M_PATH` admits any `.json` under `src/modules/<key>/`. With a test file in the diff,
`src/modules/drafts/package.json` adding a dependency → **M**, and `src/modules/drafts/tsconfig.json` setting
`"strict": false` → **M**. §3's H column names `package.json` and the lockfile, and §4.3 says "configuration" is not
L; it is not called out as not-M. **Needed:** any `package.json`, lockfile, `tsconfig*.json`, `*.config.*` or dotfile is
H wherever it sits, with a test.

### F5: cross-module and side-effect reach (Minor)

§4.1 justifies "more than one module: H" because "a cross-module change goes through a port or event and its
contract". The rule looks only at paths. `src/modules/drafts/domain/y.ts` adding
`import { users } from '../../identity/internal/repo'` → **M**. A module job file that sends mail
(`src/modules/drafts/jobs/send-digest.ts`) → **M**, although duplicate external side effects and lost jobs are
stop-the-line classes in `CONTRIBUTING_AGENTS.md`. **Needed:** an added import that resolves into another module
(`../../<other>/` or `@/modules/<other>/`) is H; and either `job`, `jobs`, `queue`, `outbox`, `cron`, `worker`, `mail`,
`email`, `notify` join the path words, or §3 says why M's Reviewer and Tester are enough for them.

### F6: deleted lines (Info)

Signals read added lines only. `apps/web/components/NewHero.tsx` with only `-  if (!flags.newHero) return null;`
classifies L. The flag reminder catches this if the Reviewer reads the diff; one sentence in §4.2 saying deletions are
not scanned would make the limit visible.
