## 4. The cases, the proof and the harness

### 4.1 42 rls-smoke cases (`tests/db/identity/isolation-cases.mjs`, `lifecycleVisibilityCases`)

Since batch 170 no client can write `lifecycle_state`, so each case moves **workspace A, the populated one**,
as the connection role inside its own rolled-back transaction. Three runner fields carry that
(`tests/db/identity/run-isolation.mjs`): `before`, a read as the case's identity before the move, which must see
what it demands or the case fails at phase `before` (no family passes vacuously, RFC §5/1); `ownerFirst`, run
only after the role reads back as `none`; and a connection-role witness, because in a blocked workspace no
client identity can see the target row.
