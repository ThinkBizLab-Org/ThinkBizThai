### N1: a multi-line import is not an import to the classifier (Major)

`IMPORT_SPECS[0]` is `/\b(?:import|export)\b[^'"`;]*?\bfrom\s*['"]([^'"]+)['"]/g`, applied to each added line on its
own. Prettier (and any formatter with a print width) writes a named import that does not fit on one line as

```
import {
  deleteDraft,
} from '../lib/delete-draft';
```

and the line `} from '../lib/delete-draft';` carries no `import` keyword, so no specifier is found. Measured with
`classifyTier` from a script outside the repository, and through the CLI on a throwaway git repository whose base holds
both classifiers (so the output says `classifier copy: the base's`):

| Probe | Added lines | Tier |
|---|---|---|
| N1 (CLI) | `apps/web/components/DangerZone.tsx`: the three-line import above of a `'use server'` file in `apps/web/lib/`, and `<button onClick={() => deleteDraft()}>` | **L** (the same import on one line: **H**) |
| N1m | the same in `src/modules/drafts/ui/`, `drafts` allowlisted | **L** |
| N1p | `import {` / `  useMutation,` / `} from '@tanstack/react-query';` in `apps/web/components/` | **L** |
| N1x | `import {` / `  users,` / `} from '../../identity/internal/repo';` in `src/modules/drafts/domain/`, with a test | **M** (should be H by §4.2 item 8) |
| N13 | `export {` / `  del,` / `} from '../lib/del';` in `apps/web/components/` | **L** |

This is the shape of my F1 (an irreversible deletion reached from an L PR), now through the rule the RFC names as
fail-closed: §4.2 item 10 (b) says an L file "imports only `react` and files that exist at the head and are themselves L
paths", §4.2 item 8 says a cross-module import is H, and §4.5 lists "L's imports" among the allowlists that fail closed.
The Reviewer's written confirmation (§4.3) still stands behind L, which is why this is not stop-the-line; nothing stands
behind item 8 at M except the M readers, and the RFC does not ask them to look for it.

**Needed:** find specifiers without requiring the keyword on the same line (for example, any `from\s*['"]...['"]`, plus
`import\s*['"]...['"]`, `@import`, `import(` and `require(`; or join the file's added lines before scanning), fail closed
on anything that looks like an unterminated import (`import {` or `export {` with no `from` on the line), pin N1, N1x and
N13 in the review-tier test, and kill the mutant that restores the same-line form. If the Author prefers to keep the code,
§4.2 items 8 and 10 (b) and §4.5 must instead say the import rule is a denylist too, and Q-030-4 must say so to the Owner.
