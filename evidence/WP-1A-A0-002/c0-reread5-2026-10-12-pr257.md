### C0-257r6-1 (advisory): macOS folds more than letter case, and `.ENV.EXAMPLE` is refused

- The fix makes every name refusal and every name the guard collects match "in any letter case" with the regex `i`
  flag. The stated reason is that macOS opens `.Config/postcssrc.json` for `.config/postcssrc.json`. APFS's
  case-insensitive matching goes further than JavaScript's non-Unicode `i` flag, though. **Measured on this Mac
  (APFS):** writing `apps/web/poſtcss.config.mjs` (U+017F LATIN SMALL LETTER LONG S) overwrote the tracked
  `apps/web/postcss.config.mjs`. That is one file to the file system. Then, with `postcss.config.mjs` removed and
  `apps/web/poſtcss.config.mjs` holding `plugins: { "../../db/p.mjs": {} }`, the text reader exited 0, and reading
  `apps/web/postcss.config.mjs` returned that content. A `.poſtcssrc.json` also passed (exit 0). `tſconfig.json` is the
  same class, because `tsconfig` contains an `s`. I restored both files I touched (`git checkout`), and `git status` was
  clean after.
- **Reach:** local macOS runs only. On Linux, where CI builds, no tool opens `poſtcss.config.mjs` for
  `postcss.config.mjs`, so the CI gate is unaffected. I did not measure whether Turbopack opens its PostCSS
  configuration by name (in which case APFS's folding applies) or matches it against a directory listing (in which
  case it does not). I did not build.
- **Possible fix, optional:** the `u` flag with `i` (`/…/iu`) uses Unicode simple case folding, under which `ſ`
  matches `s` and U+212A KELVIN SIGN matches `k`. Normalising names with `NFKC` before matching would do the same.
  A1 owns how much this weighs. A1 said it would raise no further routes of the round-five kind against this PR, and
  I raise this as text accuracy only: "any letter case" is true for JavaScript's case mapping, not for everything the
  file system treats as one name.
- **Nit, harmless:** `TRACKED_ENV_FILE` now matches in any case, but the `.env.example` exception compares the base
  name exactly. So a tracked `apps/web/.ENV.EXAMPLE` is refused [measured: exit 1]. That is stricter, not looser.
