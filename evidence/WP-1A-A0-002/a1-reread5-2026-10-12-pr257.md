### A1-257-10 (Low): closed

My round-four fix asked for (a) every workspace `package.json`'s `scripts` held to an allowlisted shape, and (b) the
records to say that repository code running in the `application` job after the guard is a residual held by review, not
by a check; optionally (c) the guard again immediately before the build. All three are on the head.

- **(a) Scripts pinned, measured.** `workspaceScripts` in `scripts/app-dependency-allowlist.json` admits
  `apps/web: { "build": "next build" }`; `workspaceScriptProblems` is applied to every non-root `package.json` the
  configuration walk collects. On the real tree, each with the guard (`--require-parser`):
  `prebuild` hook **exit 1** (also staged), `postbuild` hook **exit 1**, `build` = `next build && node ...` **exit 1**,
  an extra `test` script **exit 1**, `scripts: {}` **exit 1**, `scripts` as an array **exit 1**. No `scripts` key:
  exit 0, and then `npm run build --workspace apps/web` has no script to run and fails closed. A duplicated `scripts`
  key (first with `postbuild`, last clean): exit 0, and `npm run` in `apps/web` lists only `build` (npm and the guard
  both take the last key; they agree). The root's scripts stay pinned by the test-integrity tooling, as the text says.
  Mutation: `workspaceScriptProblems` returning `[]` makes the guard exit 1 on its own controls ("control ... a
  prebuild hook ... was not refused") and `app-boundaries.test.mjs` fail 1 of 28.
- **(b) The residual stated.** RFC-2026-029's "Build configuration, and what the build included", the CI comment,
  `configShapes.$comment` and `workspaceScripts.$comment`, the headers of `app-boundaries.mjs`,
  `verify-app-boundaries.mjs` and `verify-app-build-graph.mjs`, and the handoff's first known limitation now say the
  shapes, refusals, pinned scripts and empty `NODE_OPTIONS` hold *what configuration can make a build tool load*, not
  all code that runs, and that code the repository runs in CI after the guard (a test, a page at prerender, build-time
  code it imports) could still write files or change the output, a residual held by review of every pull request. That
