- **A1-257-10 (Low, open). "Code that runs during the build is held by the shapes and refusals" is still wider than
  what is held: the web package's own npm scripts are unpinned, and repository code that runs in the `application`
  job after the guard can write what the guard refuses.** The fix's text (RFC-2026-029's "Build configuration, and
  what the build included"; the CI comment; `configShapes.$comment`; the graph check's header; the handoff's first
  known limitation) says build-time code is held by the configuration shapes, the `.config/` and `.env` refusals and
  the empty `NODE_OPTIONS`. Measured on the real tree at the head, in the CI job's order and environment:
  1. **`apps/web/package.json` scripts.** `"prebuild": "node ../../db/probe-a1/post.mjs"` and the same as
     `"postbuild"`, with `"build": "next build"` unchanged: `verify-app-boundaries.mjs --require-parser` exit 0,
     `verify-app-dependencies.mjs` exit 0 (its lifecycle list is the install hooks only),
     `verify-test-coverage-floor.mjs` exit 0 (it pins the root's check chain, not a workspace's scripts); CI's
     `npm run build --workspace apps/web` ran **both** hooks (2 runs logged), and the graph check exit 0. A `postbuild`
     runs after `next build` writes its traces and maps and before `verify-app-build-graph.mjs` reads them, so it can
     rewrite the output the check reads (round four showed what a write into `.next/server/chunks` buys). npm runs
     `pre*`/`post*` implicitly, so the hook is easier to miss in a diff than a changed `build` command.

### Advisories (not graded, no press condition)

- **The refusal patterns are case-sensitive; macOS's filesystem is not.** `apps/web/.Config/postcssrc.json` (capital
  C) passes the guard (exit 0), and on macOS (APFS, case-insensitive) Turbopack loads it: the `db/` plugin ran (1 run
  logged). On CI's Linux runner the name does not match and Turbopack does not load it, so this is a local-build gap,
  the same kind the test-integrity guard already closes for `.NPMRC` by comparing names case-insensitively
  (`assertNoPackageManagerConfig`). The `.config/`, `.postcssrc*`, Babel, Vite, vitest-workspace and `.env` patterns
  could take the `i` flag. Not measured: a case variant of `postcss.config.*` beside the real one.
- The earlier advisories stand: runtime loaders in a page (`eval("import('pg')")`, `new Function`,
  `process.getBuiltinModule`), and the `application` required check, which A0 adds after the merge as the disposition
  §6 (b) records; until it is required, a red graph check does not block a merge on its own.
- The `NODE_OPTIONS: ''` belt is measured locally with an empty variable in the environment; that GitHub's runner
  exports an empty `env` value as a defined, empty variable is not measured by A1 (the job's log will show the value;
  Q0/R0 read CI).
