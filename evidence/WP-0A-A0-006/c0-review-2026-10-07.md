`files_modified` of the 2026-09-10 increment. Its `tests` say "npm run check … exit 0", which was measured

not exist yet. The task that spawned me named a "handoff commit after 89c9ec9f", but the remote has none.

cannot merge. **Owed by the Author:** run `npm run refresh:handoff` as the last commit, after this review
commit and any F2/F3 fixes. That commit records the measured counts and exit codes, and it makes the
reverify file's §6 resolvable. A green `bootstrap` on that head is also required.

WP-0A-CON-007 and WP-0A-CON-008, each a digest added or recomputed in `integrity-manifest.json`.
WP-0A-A0-001's `amended_by[0..3]` record four, each with `acknowledgement_required_from: /root/r0_steward`.
`4cce106` pointed `recorded_on` at `WP-0A-A0-002.json`. `c5a48a8` then removed that pointer as "dangling",
because no record existed. The pointer was removed and no record was added. The disposition commit
`234693c` also recomputed RFC-2026-015's digest in `integrity-manifest.json`, so a sixth edit to an
A0-002 path exists. It was made on a disposition branch and it is structural.

The new `_run_id_disambiguation` reads: "neither WP-0A-A0-001's ownership.amended_by nor any
contract-catalog schema records an amendment by WP-0A-A0-006 … No such acknowledgement is owed by or to
this package, so the succession moves nothing here". The first half is literally true. The conclusion
is not. WP-0A-A0-006 **did** amend a WP-0A-A0-001 path. Under that package's own convention the
amendment's acknowledgement would have been owed by `/root/r0_steward`, and so, after step 2 item 2, by

it. Reasoning from a missing record to "nothing owed" is the same defect class this package's re-audit was
written to catch.

No tenant, secret or contract is affected. The edits added one registry line each and were reviewed in
PR #45's diff. This is not stop-the-line. **Owed:**
- **In this PR** (manifest strings only): reword `_run_id_disambiguation` to say that the amendment exists
  and is unrecorded, not that none is owed, and add an open blocker naming the three owners' missing
  `amended_by` entries and who acknowledges each.
- **By the owners** (WP-0A-A0-001, WP-0A-A0-002, WP-0A-CON-008, outside this package's paths): the
