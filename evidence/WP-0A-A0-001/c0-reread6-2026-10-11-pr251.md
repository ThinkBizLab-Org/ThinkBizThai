**Advisory.** Each fails closed under "If it is unclear whether an edit is additive, it is governance" (line 119), so

and -2 fixed there.

- **C0-251r6-1. `FK_ACTION_EXEMPTIONS` is named both additive and governance in the same bullet.** Line 100 lists
  `FK_ACTION_EXEMPTIONS` among `run.mjs`'s admission lists, an entry in which "is additive only for an object the same
  pull request adds and only when A1's confirmation names it". Line 101–102 then says "an entry in any `*_EXEMPTIONS`
  list … is governance", and `FK_ACTION_EXEMPTIONS` matches `*_EXEMPTIONS`. It is the list `run.mjs` line 141 calls
  "the irreversible-deletion stop-the-line class". A1's recommendation (A1-251r5-1) did not put it among the admitting
  lists, and A1 said it never confirms an entry there (`a1-reread5-2026-10-11-pr251.md` lines 78–80). So the outcome
  is governance by two routes (the fail-closed sentence, and A1 must name it), but the text contradicts itself on the
  one list where the answer matters most. Also, `LIFECYCLE_WRITERS` is not one of "`run.mjs`'s" lists: it is in
  `scripts/db/audit-producer-rule.mjs`, which `run.mjs` imports. **Fix:** drop `FK_ACTION_EXEMPTIONS` from line 100
  and write "`run.mjs`'s admission lists, or those of a module it imports (`PERMISSIVE_POLICIES`, …,
  `LIFECYCLE_WRITERS` in `scripts/db/audit-producer-rule.mjs`, and the like)".

  the fifth revision's sentence; the bullet below it (line 93) now says such edits "take the risk lane" once both
  confirmations exist, never the fast lane. A reader of the table alone gets the old rule. **Fix:** "An additive guard
  edit (below) takes the risk lane once A1 and Q0 confirm it."
- **C0-251r6-3. §4's "(Q-034-6)" points at a case Q-034-6 excludes, and Q-034-6 (ii)'s parenthesis reads as a
  definition.**

    Q-034-6 (ii) asks only about a batch that is governance "not because it edits an RFC, CI or another path

    whose presser is §5 item 6 and the Owner's standing directions as they stand.

    as additive)". §2.4 says this RFC's path list also adds `docs/**`, `.agents/**`, package files and lockfiles, and

  - **Fix:** in §4, "… or renames a test, is governance: the first under RFC-2026-025 §5 item 6, the second Q-034-6
    (ii)"; in Q-034-6, "(for example, a guard edit A1 or Q0 does not confirm as additive)".
