## 2. The design

The design is sound in shape, and I accept it as the minimal static design. The walk starts from every discovered test file. Every reached
module must be a `node:` builtin or a `./`/`../` specifier free of URL metacharacters. It must be lexically inside the root,
reached through no symlink at any component, a regular file with its realpath inside the root, and digested. The walk
refuses computed `import()`, `require` and `createRequire`. Containment and digests are each needed for
the reasons the Author gives. A static walk instead of a loader hook is a fair choice: a hook changes the pinned runner
command and must reach spawned children. The walk is called by both `verifyTestCoverageFloor` and the post-run
`assertDeclarationsMatchExecution` (read, and pinned by a test). A1 T1 is addressed as asked: the post-run pass reads
each test file once, hashes that buffer (exit 86) and counts declarations from the same buffer.

The three named routes are closed **for `.mjs` / `.js` modules reached by static import syntax**. In the probe clone I
saw the Author's (a), (b)-symlink, (b)-`../` and (c) refusals reproduce as unit tests (43/43). The guard is 0 on the
clean tree. The gaps are at the edges of that sentence (§3).

## 3. Findings

### F1 (blocking): a static import of a module that is not `.mjs`/`.js` is checked for containment but never walked

`assertImportClosureContained` checks a reached module for containment and digest. When it pops the module, it skips
it with `if (!file.endsWith('.mjs') && !file.endsWith('.js')) continue; // a JSON import is a leaf`. JSON is a leaf,
but `.cjs` is executed code, and so are `.mts` / `.ts` / `.cts`: Node 24.20.0 strips types by default. Such a module
passes as long as it is inside the root and digested. Nothing reads what it loads.

Measured in the probe clone (route (c) shape, the same edits the Author's own route (c) row makes):

| Probe | Edits | Guard | Outside code ran |
|---|---|---:|---|
| P1 `.cjs` leaf: `import './e4-helper.cjs';` prepended to `test-kits/capability-profile.test.mjs`; `e4-helper.cjs` = `require('<outside>/out.cjs')` | new file, its manifest key + `DIGESTED_FLOOR` line, `regenerate:manifest` | **0** | yes: `node --test` on the suite 4/4 pass, marker written outside the clone |
| P2 `.mts` leaf: same, `e4-helper.mts` = `import '<outside>/out.mjs'; const x: number = 1;` | same | **0** | yes, marker written |

This is exactly what the task required to fail: a module in the static import closure that does not resolve inside the
repository. The minimal fix is an extension allowlist for reached modules: `.mjs`, `.js` (walked) and `.json` (leaf).
Every other extension, including an extensionless file, gets exit 92, plus a test for `.cjs` and `.mts`.
(`package.json` declares no `"type"`, so a `.js` file is CommonJS. It is walked with the ESM scanner, and its `require`
is refused, so `.js` fails closed.)

(`eval`, `vm`, and `module.register` belong to the same class; I did not complete a `register` probe.) These need a

### F3 (non-blocking): `function* test` shadows `test` and passes `assertTestBindingIntact`

`[10]` says the check "refuses any other use of the identifier test in code than a call, a member access or an object
key". A generator declaration puts `*` between `function` and the name. The check sees `previousChar = '*'` and an
empty previous word, then `next = '('`, and treats it as a call. Shadowing matrix (direct calls to the exported function):

| Form | Result |
|---|---|
| `{ function* test() {} test('a', …) }` / `function *test` / `async function* test` | **accepted** |
| `const test =`, `for (const test of`, `catch (test)`, `(test) =>`, `{ a: test } =`, default param, class field | refused (93) |
| `class A { test() {} }`, `{ test() {} }` (method names, bind nothing) | accepted, correctly |
| label `test:` in a block | refused (conservative false positive, harmless) |

A standalone file with the generator form ran `tests 1 / pass 1`, and none of its two `test('…', () => assert.ok(false))`
bodies ran. In the repository, exit 88 still catches this unless it is balanced, which is Q0-F2 and still open. Fix
(cheap): treat a preceding `*` as a declaration. Until then, `[10]`'s "any other use" needs "except a generator
declaration".
