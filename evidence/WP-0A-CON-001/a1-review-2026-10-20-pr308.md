## 2. Does the vocabulary give a worker anything the code reserves elsewhere?

No. Each worker row of `x-lifecycle.transitions` is a function the code already admits on a held lease:

- **claim** (`ready` → `leased`) is `claim`, refused unless `claimRefusal` is null; the derived `ready` condition is
  exactly `claimRefusal === null` (same five tests, same order).
- **heartbeat / complete / fail** each require `holdsLease` (job id, workspace id, owner, attempt, unexpired), and the
  `actors.worker` text says so, including `lease_lost` with nothing written. The fence is described, not loosened.
- **dead-letter**: the worker reaches `dead_lettered` only by `fail` at `attempt >= max_attempts`, which is the code's
  `outcome: 'dead_letter'`; there is no worker act that spends the budget otherwise. The clock reaches it by lease
  expiry with nothing written. Both match `isDeadLettered`.
- **cancel** is assigned to the command path only (four rows), never to the worker. `worker.ts` never calls
  `requestCancel`, `enqueue` or `get`. No row lets a worker clear `cancel_requested_at`, and `never` states only cancel
  writes it.
- **lease expiry** is the clock's, with no write; no worker act shortens or releases a lease except `complete`/`fail`
  (both fenced). `claim` replaces an expired lease only from `ready`.
- `cancelling` admits heartbeat, complete and fail: that is the code (`holdsLease` only), stated openly, and the
  consequence (cancellation does not reach a running handler) is in `not_settled` (JB-006), not hidden.
- Counted: 14 transitions (enqueue, due, claim, heartbeat, complete, fail ×3, lease expiry ×2, cancel ×4), 7 states;
  terminal flags agree with `never` (completed and cancelled absorb; dead_lettered leaves only by cancel).

Lease and attempt rules: `attempt + 1` per claim, `lease_expires_at = now + timeout_seconds + grace`, heartbeat takes
the later of current and `now + extension` — all as coded; the numbers are left as D6 kernel parameters, not contract
values, so nothing is fixed that A1 has not seen.
