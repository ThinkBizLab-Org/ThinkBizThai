**Ruling on the `ratchets-bite.test.mjs` repoint. It is inside K1 and does not void it.**

1. K1 has two parts. The *voiding* clause applies only to bytes under `ctr-sec-001/`: "Any other byte changed under
   `ctr-sec-001/` voids this signature." The outside list names what the increment is *permitted* to move. The
   ratchet file is outside `ctr-sec-001/`, so it cannot void K1. The only question is whether it is an unpermitted
   extra.
2. It is a census assertion in substance. The reversal checks that `shared-kernel-contract-catalog.test.mjs` notices
   a Draft contract counted as Candidate. To do that it must name a contract that *is* Draft, so which name it uses
   depends on the census. The census move forces the repoint. Left on CTR-SEC-001, the reversal becomes a no-op, and
   `mustNotice` fails for the wrong reason. A census move that left it alone would break the suite. When I wrote
   "census assertions" in K1, I meant what RFC-2026-031 §4.5 means: the assertions that must move with the census.
   §4.5 lists three files and does not list this one. I treat that as an omission in the list, not as a boundary I
   drew.
3. It weakens no security guard. Measured: the repointed reversal still bites (NTF to Candidate makes the Draft count
   1, not 2, and the catalog test fails). SEC, now Candidate, is pinned by name in
   `shared-kernel-envelope-contracts.test.mjs` (`PROMOTED_2026_10_09`) and by `status`/`index_status` in
   `catalog-registry.test.mjs`. Moving SEC to `Frozen` by hand fails two tests (§1). The guard against an unsigned
   Draft → Candidate move now protects the two contracts that still need it.
4. The edit is declared openly. It appears in `ownership.amends_without_owning` item (5), in `open_blockers[23]` and in
   the handoff, it was flagged for my ruling, and `verify-branch-scope.mjs` accepts it.

Note for the next Candidate step (not a finding on this PR): when CTR-NTF-001 moves, no Draft contract will be
left, and this reversal needs a census-independent design. The `CTR-ERR-001 → "Released"` reversal already has one.
That step owes the redesign. USG's step does not, because NTF is still Draft then.
