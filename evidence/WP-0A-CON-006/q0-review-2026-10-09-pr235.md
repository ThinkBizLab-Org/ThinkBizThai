### 1.1 `main` moved during the run

`origin/main` moved from `65695129` to `7261094e` (PR #232, WP-0A-A0-004) between my fetch and the scope check. Run
against the new tip, `verify-branch-scope.mjs origin/main WP-0A-CON-006` exits **73** and names five WP-0A-A0-004
paths. That is an artefact of the guard's two-dot diff (`${base}..HEAD`, line 127). The branch does not contain #232,
so the diff shows #232's files as if this branch had changed them. Against the merge-base it exits 0. `classify-records-only.mjs`
gave the same output against both bases. The paths #232 brings and this PR's 11 paths do not overlap
(`comm -12` is empty). So a sync merge of `main` into this branch can qualify as mechanical under clause (b) below.
Until that merge, the guard reads red against the moving tip.
