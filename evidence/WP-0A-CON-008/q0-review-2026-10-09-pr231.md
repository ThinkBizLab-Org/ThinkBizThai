## 5. Findings

**Stop-the-line: no. Blocking: none.**

Advisory:
- **A1.** Removing `declared_gaps` from `MANIFEST_KEYS` (S12) goes unnoticed at this head. No manifest carries the key,
  so the reversal changes nothing that is measured. It fails closed: a later freeze increment would be refused, not
  admitted. It becomes noticed once a manifest carries a gap. One more synthetic control would close it now: a
  `MANIFEST_KEYS.includes('declared_gaps')` assertion in the synthetic test.
- **A2.** The `ratchets-bite` probe reverses 5 of the roughly 14 new rules. The other rules are noticed by the
  synthetic test when reversed (S6–S11 and S13–S15, as measured here), but no ratchet keeps checking that this stays
  true. That is acceptable for §7.1, which named three. It is worth widening when the file is next touched.
- **A3, for the first increment that adds `declared_gaps`.** With the gap pinned, a JSON reversal that empties the
  owner or moves `closes_before` is also caught by `DECLARED_GAP_DIGESTS` (`rewrote`; C03, C05). `mustNotice` checks
  only for a non-zero exit, so those JSON reversals would still pass with the shape rule deleted: the earlier
  "wrong reason" trap. The deletion reversal (C11) does not have this problem. That increment should either assert
  the failing message or keep the source probes S1 and S2 as the discriminating measurement.
