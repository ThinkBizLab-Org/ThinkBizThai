## 3. Residuals, graded

- **A1-294-1 (Info).** The new cases pin four variables (`GIT_DIR`, `GIT_WORK_TREE`, `GIT_INDEX_FILE`,
  `GIT_OBJECT_DIRECTORY`), not the class. A later edit that replaced the prefix strip with a named list of those four
  would still pass them while reopening `GIT_CONFIG_*` (Probe B, hook execution) and `GIT_COMMON_DIR`. The code today
  strips the class, so nothing is open; a third redirection carrying `GIT_CONFIG_COUNT`/`KEY`/`VALUE` with a
  `core.hooksPath` marker would pin it. Advisory.
- **A1-294-2 (Info).** `ci-guard-behaviour`'s `run()` spreads `options` after `env: CHILD_ENV`, so a future caller
  passing its own `env` would replace the scrubbed one. No caller passes `env` today (all pass `cwd` only). Advisory.
- **A1-294-3 (Info).** Configuration that reaches git without a `GIT_` name — `HOME`/`XDG_CONFIG_HOME` (a user's global
  `core.hooksPath`, `init.templateDir`), the system gitconfig — still reaches the scenario repositories. It is outside
  A1-292-2's class (a caller's hook-time `GIT_*`), is the same as `ratchets-bite.test.mjs` since #292, and is the
  operator's own configuration rather than a redirect into a caller's repository. Advisory.
- **A1-294-4 (Info).** `classify-review-tier.mjs` adds `GIT_LITERAL_PATHSPECS=1` to the environment it passes to
  git, after the strip. That is the classifier's own setting, points at no repository, and is not inherited from a
  caller. Not a residual of this class; recorded so nobody reads it as one.
