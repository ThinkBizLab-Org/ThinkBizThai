## 2. How the new rules are measured with no gap on any contract (Q0-A1)

Q0 (`q0-review-2026-10-09-pr229.md`, A1) found that the three JSON reversals of §7.1 (2) cannot be measured in this
PR: with no manifest carrying `declared_gaps`, "owner emptied" and "one gap deleted" have no target, and a reversal
that inserts a gap is caught first by the pin for the wrong reason. The "Frozen" rule also passes vacuously while no
contract is Frozen.

So each rule is measured in two layers, and no contract is edited:

1. **Synthetic controls inside the suite.** The test "the declared-gap and Frozen rules each reject a synthetic
   violation" builds a valid synthetic Frozen contract (`CTR-ZZZ-001`) with four declared gaps, one of each kind and
   each `source` form. The valid one must pass every rule (the negative control), and a gap of exactly 80 characters
   must pass. Then 22 single violations must each be reported **for their own reason**, matched by message: owner
   emptied, owner outside the list, `closes_before` outside the list, kind outside the list, 79 characters, an extra
   key, a missing key, another contract's id, a duplicate id, an unresolved field source, an unresolved
   `open_blockers` index, a non-array, one gap deleted, one reworded, one added unpinned, a retired id reused, Frozen
   with no `declared_gaps`, an accepted gap undeclared, `untestable_by_schema` undeclared, `untestable_by_fixture`
   undeclared, a "Draft only." boundary and a "Candidate only;" boundary. Two more: a Frozen manifest whose index entry
   reads Candidate is reported, and a Candidate manifest is not held to the Frozen rule.
2. **A source-reversal case in `ratchets-bite.test.mjs`**, "the declared-gap ratchet notices each rule reversed in
   its source". It copies the repository, reverses five rules in the suite's own source, and requires
   `catalog-registry.test.mjs` to fail each time: the owner check, the `closes_before` check, the accepted-gap
   coverage rule, the drop direction of the pin, and the "Candidate only" half of the boundary check.

**Measured, outside the suite, before committing:** each of the five source edits applied alone made
`node --test test-kits/contracts/catalog-registry.test.mjs` exit 1, and in each case the only failing test was the
synthetic-controls test, failing on its "must be reported for its own reason" assertion. None failed by a syntax
error. The file was restored byte for byte afterwards (`cmp`).
